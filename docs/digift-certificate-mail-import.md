# Импорт сертификатов Digift из почты Bitrix24

Источник — ящик `v2sportdress.ru@mail.ru` внутри Bitrix24. Прямого подключения к mail.ru нет. Обрабатываются только письма с темой `Отчет по подарочным картам` и отправителем `noreply@digift.ru`.

Скрипт получает ящик через `mail.mailbox.list`, ищет письма за последние 3 дня через `mail.message.list`, загружает тело через `mail.message.get` (REST 3.0, scope `mail`). До создания карточек сверяет код, номинал, даты и контрольный итог письма. Повторные письма не создают дубли. Для существующих карточек допускается заполнение пустых дат; использованные суммы и остатки не меняются. Противоречия в номинале или датах блокируют запись всего отчёта и попадают в результат запуска. Даты хранятся в полях `begindate` и `closedate`, но не влияют на проверку и использование сертификата.

Локальная проверка без почты: `node --test test/digift-certificates.test.js`. Тесты используют таблицу с тремя сертификатами из скриншота, а также имитацию Bitrix REST.

Для чтения настоящего письма нужен HTTPS-вебхук Bitrix24 REST 3.0 от пользователя, имеющего доступ к указанному ящику, со scope `mail`. В `bitrix-loyalty-mvp/.env` установить `DIGIFT_BITRIX_MAIL_WEBHOOK_URL`. Вебхук не следует помещать в репозиторий или документацию. Права администратора в UI сами по себе не передаются серверному процессу. После настройки запустить `node scripts/check-digift-mail.js`: по умолчанию это только план без записи. `--apply` создаёт карточки/заполняет даты после проверки плана.

Автоматический опрос по московскому времени каждые 10 минут с 09:00 до 10:30 включается только переменной `DIGIFT_CERTIFICATE_IMPORT_ENABLED=1` на сервере лояльности. По умолчанию он выключен. Поиск за 3 дня позволяет подобрать письмо при перезапуске сервера или пропущенном утре. Запуск более одного экземпляра импортёра одновременно не предусмотрен.

Ограничения до публикации: нужен пробный вызов настоящего `mail.mailbox.list`/`mail.message.get` с нужным вебхуком и проверка реального HTML письма. Отправитель в поле письма не является криптографическим доказательством подлинности; для полного исключения подделки потребуется подтверждение Digift через их API или проверяемую подпись. При 500 и более карточках СП импорт остановится до реализации постраничной сверки.
